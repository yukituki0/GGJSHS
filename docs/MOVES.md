# Guilty JSHS 기술표

→ = 상대 쪽, ← = 반대쪽. 게임 안에서는 **일시정지(START) → 기술표**에서 볼 수 있다.
(기술을 바꾸면 `scripts/game.gd`의 `MOVE_LISTS`와 이 문서를 같이 고친다)

## 공통 조작
| 입력 | 이름 | 설명 |
|---|---|---|
| P / K / S / HS | 기본기 | 서서 / ↓ 앉아서 / 공중에서 |
| P → K → S → HS | 개틀링 | 맞히거나 막히면 더 강한 버튼으로 이어짐 |
| 기본기 → D 계열 | 필살기 캔슬 | 기본기가 맞거나 막히면 필살기로 이어짐 |
| RC | 로만 캔슬 | 공격을 즉시 취소 (텐션 50%) |
| →→ / ←← | 대시 / 백스텝 / 공중 대시 | 같은 방향 두 번. → 계속 누르면 달리기 |
| ← 누르고 있기 | 가드 | 길티기어처럼 뒤 = 가드. ↙ = 앉아서 가드 (하단 막기). 상대가 공격할 때는 뒤로 걷지 않고 제자리에서 가드 자세 |

| (시스템) | 근접 가드 | 상대 기술이 닿을 만한 거리(판정 끝 + 60px)에서 발생~지속 중일 때만 ←를 누르면 제자리 가드 자세. 멀리서 헛친 기술엔 계속 뒤로 걸을 수 있다. 잡기는 반응 안 함 |
| (시스템) | 카운터 히트 | 상대가 공격을 내는 중(발생~지속)에 때리면 COUNTER: 데미지 +10%, 경직 +8F, 히트스톱 +6F |

트레이닝 판정 보기 색 (길티기어 판정 보기 모드와 같게): 밀어내기 노랑 · 맞는 판정 초록 (카운터 상태면 하늘색) · 공격 빨강 · 잡기 범위 보라

버튼은 길티기어처럼 **P · K · S · HS · D · RC 6개**. 대시와 가드는 스틱(키보드는 WASD)으로 한다.
| D + HS | 오버드라이브 | 텐션 50% |

### 🧪 CHEMIKID (화학)
| 입력 | 기술 | 분야 | 설명 |
|---|---|---|---|
| D | 플라스크 투척 | 산·염기 | 포물선, 깨지면 산성 웅덩이 (하단, 지속 데미지) |
| → + D | 촉매 돌진 | 반응 속도 | 빠른 돌진 공격 |
| ↓ + D | 발열 반응 | 열화학 | 위로 폭발하는 대공기, 시작 무적 |
| ← + D | 중화 반응 | 산·염기 | 반격 자세 → 받아침 |
| 공중 D | 앙금 생성 | 침전 반응 | 바닥에 굳어 투사체를 막는 벽 |
| D + HS | 테르밋 반응 | 산화환원 | 연쇄 폭발 + 불꽃 기둥 |
