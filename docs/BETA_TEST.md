# Guilty JSHS 베타 테스트 체크리스트

축제(10/31) 전에 직접 해 보면서 확인할 것들. 이상한 게 있으면 **어떤 캐릭터로 / 무엇을 했더니 / 어떻게 됐는지** 적어 두기.
(가능하면 F2로 판정 박스를 켜고 스크린샷도 같이)

표시: ⬜ 아직 / ✅ 괜찮음 / ❌ 문제 있음 (옆에 메모)

---

## 1. 실행 · 메뉴 (5분)

| | 확인할 것 |
|---|---|
| ⬜ | 타이틀 → 아무 버튼 → 모드 선택으로 넘어간다 |
| ⬜ | 타이틀에서 20초 가만히 두면 **데모(CPU끼리 대전)** 가 나온다. 아무 버튼이나 누르면 타이틀로 돌아온다 |
| ⬜ | 데모 대전이 끝나면 저절로 타이틀로 돌아온다 |
| ⬜ | F11 전체 화면 / F1 키보드↔스틱 전환 / ESC 종료 확인 창 |
| ⬜ | 조작법 화면: 1P·2P 키가 실제 키와 같다 (버스트 줄 포함) |
| ⬜ | 캐릭터 설정집: 좌우로 6명 넘기기, 체력 막대가 맞게 나온다 |
| ⬜ | 캐릭터 선택: RANDOM 룰렛이 빙글빙글 돌다가 멈추고 번쩍인다 |
| ⬜ | 언어 바꾸기 (한국어 / English) — 글자가 잘리거나 겹치는 화면이 없다 |

## 2. 기본 조작 (트레이닝, 캐릭터 1명으로)

| | 확인할 것 |
|---|---|
| ⬜ | 걷기 앞/뒤, 66 대시, 44 백대시, 점프, 2단 점프, 공중 대시 |
| ⬜ | 뒤를 누르고 있으면 서서 가드, ↙ 이면 앉아 가드 (하단기를 서서 막으면 맞아야 함) |
| ⬜ | 공중에서 내려찍는 기술(중단)을 앉아서 막으면 맞아야 함 |
| ⬜ | P → K → S → HS 순서로 이어지는 콤보 |
| ⬜ | 잡기: 붙어서 → + HS / ← + HS |
| ⬜ | 로만 캔슬(RC): 텐션 50% 이상일 때 기술 도중 캔슬 |
| ⬜ | 오버드라이브(D + HS): 텐션 50% 소모 + 컷인 |
| ⬜ | 짧은 기술(5P 등)을 눌렀을 때 공격 그림이 **눈에 보일 만큼** 나온다 |
| ⬜ | 도발(P + K): 말풍선 + 상대 텐션 +10% / 앞 + P + K: 리스펙트 (게이지 변화 없음) |
| ⬜ | 트레이닝 ⚙ 설정: 더미 동작, 판정 보기, 입력 기록 켜고 끄기 |

## 3. 새로 넣은 시스템 (대전 모드에서! 트레이닝은 게이지가 항상 가득)

| | 확인할 것 |
|---|---|
| ⬜ | **마력(MANA)**: D 필살기 한 번에 한 칸 줄고, 0칸이면 필살기가 안 나가고 테두리가 빨갛게 깜빡인다 |
| ⬜ | 마력이 시간이 지나면 다시 찬다 (빈 칸 → 가득 약 11초) |
| ⬜ | **버스트**: 맞는 중에 D + 공격 버튼 → 상대가 날아가고 콤보가 끊긴다. 쓴 뒤 B 아이콘이 비고 천천히 다시 찬다 |
| ⬜ | 버스트를 상대가 **막으면** 빈틈이 크다 (반격당할 수 있음) |
| ⬜ | 버스트 게이지는 라운드가 바뀌어도 그대로다 (경기 시작 때만 가득) |
| ⬜ | **콤보 카운터**: 2대 이상 이어 맞히면 때린 쪽에 "N HITS / 데미지" 가 뜬다 |
| ⬜ | **콤보 보정**: 콤보가 길어질수록 한 대 데미지가 줄어든다 (같은 콤보를 짧게/길게 해서 데미지 비교) |
| ⬜ | 카운터 히트: 상대 기술 발생 중에 때리면 COUNTER 글자 + 데미지 조금 더 |
| ⬜ | 가드 게이지: 계속 막으면 차오르다가 가드 크러시 |

## 4. 캐릭터별 (한 명씩 트레이닝 → 대전)

각 캐릭터마다: **기본기 12개(5P 5K 5S 5H / 2P 2K 2S 2H / jP jK jS jH) + 필살기 6개 + 잡기 + 승리 포즈 + KO 포즈**
- 그림 크기(머리 크기)가 다른 자세와 비슷한가
- 판정(빨간 박스)이 그림의 손/발/무기 끝과 맞는가 (F2)
- 이펙트가 너무 빨리 사라지거나 엉뚱한 위치에 나오지 않는가

| 캐릭터 | 기본기 | D | →D | ↓D | ←D | 공중D | D+HS | 잡기 | 승리/KO |
|---|---|---|---|---|---|---|---|---|---|
| Chemikid | ⬜ | ⬜ 플라스크 투척 | ⬜ 불꽃 반응 (빨강·노랑·초록) | ⬜ 발열 반응 (대공, 착지 빈틈) | ⬜ 중화 반응 (반격) | ⬜ 앙금 생성 | ⬜ 테르밋 | ⬜ | ⬜ |
| Common | ⬜ | ⬜ 패킷 전송 | ⬜ 버그 설치 | ⬜ 방화벽 | ⬜ Ctrl+Z | ⬜ 이진 탐색 | ⬜ 블루스크린 | ⬜ | ⬜ |
| Globe | ⬜ | ⬜ 유성우 | ⬜ 지각 돌진 (아머) | ⬜ 지진해일 | ⬜ 별자리 잇기 | ⬜ 낙뢰 | ⬜ 태풍 | ⬜ | ⬜ |
| Chaos | ⬜ | ⬜ 만유인력 | ⬜ 운동량 던지기 (잡기) | ⬜ 전자기 펄스 | ⬜ 양자 터널링 | ⬜ 열팽창 폭발 | ⬜ 블랙홀 | ⬜ | ⬜ |
| Root2 | ⬜ | ⬜ √2 부메랑 | ⬜ 컴퍼스 찌르기 | ⬜ 적분 기둥 | ⬜ 확률 주사위 | ⬜ 피보나치 낙하 | ⬜ 랜덤 증명 (Q.E.D.) | ⬜ | ⬜ |
| Seed | ⬜ | ⬜ 씨앗 심기 | ⬜ 덩굴 채찍 | ⬜ 세포분열 | ⬜ 광합성 | ⬜ DNA 이중나선 | ⬜ 진화 | ⬜ | ⬜ |

이미 알고 있는 것 (다시 그릴 예정): **Globe 2S, Seed 2S** — 앉아서 치는 동작이 아니라 자세만 낮춰서, 판정이 허공에 떠 있음

## 5. CPU 대전

| | 확인할 것 |
|---|---|
| ⬜ | 쉬움: 처음 해 보는 사람도 이길 수 있다 |
| ⬜ | 보통: 적당히 막고 콤보도 한다 |
| ⬜ | 어려움: 빈틈을 때리고, 콤보를 많이 맞으면 버스트로 빠져나온다 |
| ⬜ | CPU가 한 기술만 계속 쓰거나 벽에 붙어 가만히 있는 등 이상한 행동이 없다 |

## 6. 밸런스 느낌 (여러 판 해 보고)

| | 확인할 것 |
|---|---|
| ⬜ | 한 판(라운드)이 너무 빨리/늦게 끝나지 않는다 (대략 30~60초면 적당) |
| ⬜ | 너무 센 캐릭터 / 너무 약한 캐릭터가 있는가 → 누구, 왜 |
| ⬜ | 필살기만 계속 써도 이기는 캐릭터가 있는가 (마력이 충분히 막아 주는지) |
| ⬜ | 투사체를 너무 많이 쏘는 캐릭터가 있는가 |

지금 숫자 (참고): 체력 Root2 400 · Common 410 · Seed 420 · Chemikid 440 · Chaos 460 · Globe 470 /
기본 콤보(2K>5S>5H>6D) 데미지 약 110~150 → 콤보 3번 정도에 KO
