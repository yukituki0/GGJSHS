# 콤보 목록

게임 안에서 실제로 이어지는지 **자동 테스트로 확인한 콤보만** 적었다 (트레이닝 허수아비 상대, 가까운 거리에서 시작).
데미지는 콤보 보정까지 들어간 값이라 상황(벽, 카운터, 상대 캐릭터)에 따라 조금 다를 수 있다.

## 읽는 법

| 표기 | 뜻 | 1P 키보드 |
|---|---|---|
| `5P` `5K` `5S` `5H` | 서서 P / K / S / HS | Y / U / I / K |
| `2P` `2K` `2S` `2H` | 앉아서(↓ 누른 채) P / K / S / HS | S + 버튼 |
| `jS` `jH` … | 공중에서 S / HS … | |
| `6K` | → + K (중단 발차기, 앉아 막기를 깬다) | D + U |
| `5D` `6D` `2D` `4D` | D / → + D / ↓ + D / ← + D (필살기, 마력 1칸) | H, D + H … |
| `OD` | D + HS 동시 (오버드라이브, 텐션 50%) | H + K |
| `jc` | **점프 캔슬**: 2H가 맞는 순간 ↑ (앞으로 뛰려면 ↗) | W |
| `>` | 앞 기술이 **맞는 순간** 다음 버튼 (너무 빨리 눌러도 5프레임까지는 기억해 준다) | |

**콤보 규칙 요약**
- 기본기는 약한 것 → 센 것 순서로 이어진다: P → K → S → HS (개틀링).
- 기본기가 맞거나 막히면 **필살기(D)로 캔슬**할 수 있다. 필살기가 맞으면 **OD로 캔슬**할 수 있다.
- **2H**는 상대를 띄운다 → ↑로 점프 캔슬 → 공중 기본기 → 공중 D.
- 같은 기술은 두 번까지만 이어진다 (5P > 5P > 5P 무한 X). 공중에서 8대 넘게 맞으면 무적이 된다.
- 3번째 기술부터 데미지가 조금씩 줄어든다 (콤보 보정).

## 모든 캐릭터 공통

| 이름 | 콤보 | 히트 | 데미지 | 메모 |
|---|---|---|---|---|
| 입문 | `5P > 5K > 5S > 5H` | 4 | 133 | 버튼만 순서대로. 처음 해 보는 사람용 |
| 하단 시작 | `2K > 5S > 5H` | 3 | 110 | 2K는 하단이라 서서 막으면 맞는다. 여기에 필살기를 붙인다 (캐릭터별 아래) |
| 띄우기 | `2K > 2S > 2H > jc > jK > jS > jH` | 6 | 184 | |
| **공중 콤보 (가장 셈)** | `2P > 2K > 5S > 5H > 2H > jc > jS > jH > jD` | 8~10 | 221~230 | 캐릭터 상관없이 제일 아프다. jc 뒤에 **조금 기다렸다가** jS |

> `5K > 5S > 5H > 2H > jc > jK > jS > jH` (7히트, 236)도 들어가지만 마지막 jD는 안 맞는다. 공중에서는 **jS > jH > jD** 세 개가 가장 안정적.

## 연습 순서 추천 (축제용)

1. **입문:** `5P > 5K > 5S > 5H` — 버튼 4개를 순서대로
2. **하단 + 필살기:** `2K > 5S > 5H > (캐릭터 기본 필살기)`
3. **띄우기:** `… 5H > 2H > ↑ > jS > jH > jD`
4. **텐션 50%가 차면** 마지막을 `OD`로
